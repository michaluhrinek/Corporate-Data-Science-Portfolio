# Procurement Automation: Email Sorting & Contract Analysis

## Project Overview
An advanced automation solution leveraging Python and Natural Language Processing (NLP) to transform procurement operations through intelligent document management and contract monitoring.

## Core Objectives
- Automate email classification and sorting
- Extract critical information from procurement documents
- Create a smart contract management system
- Reduce manual processing time for email sorting and contract management
- Enhance vendor relationship management

## Key Features

### 1. Email Sorting Automation
- Automatic email classification
- Intelligent attachment handling
- Folder organization based on content
- Minimized manual intervention e.g(sorting emails from 8 hours to 5minutes - proven!!!)

### 2. NLP-Powered Contract Analysis
- Automatic contract document analysis
- Vendor information extraction
- Critical date tracking (contract expiration)
- Risk assessment and compliance checking
