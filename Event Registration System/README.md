# Event Registration System

## Project Overview
A robust, flexible event registration solution with two implementation approaches: Google Forms and Flask-based custom registration platform. Designed for corporate event management with advanced features like QR code registration and winner selection.

## Implementation Approaches

### 1. Google Forms Version
- Quick deployment
- Easy integration
- Simple data collection
- QR code registration support

### 2. Flask Custom Platform
- Fully customizable
- Advanced data management
- Enhanced flexibility

## Key Features

### Registration Capabilities
- Detailed participant information collection
- Department-based registration
- QR code access
- Real-time data management

### Winner Selection Mechanism
- Department-based random selection
- Transparent drawing process
- Automated winner identification

4. Apply random selection algorithm
