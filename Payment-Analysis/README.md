# Payments Analysis Project

## Objective
Analyze payment operations across different systems to identify efficiency improvements and cost-saving opportunities.

## Key Features
- Historical payment trend analysis
- Performance KPI dashboards
- Predictive modeling for payment operations
- Volume analysis for leave planning
- Cross-system operational comparison

## Data Sources
- Departmental records

## Technologies Used
- Python (Polars, NumPy)
- Power BI
- Machine Learning Algorithms
